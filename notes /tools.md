# Security Tools

## Burp Suite

A web security testing platform used to inspect and modify HTTP requests and responses in authorized testing environments.

## curl

A command-line tool for making HTTP requests.

Example:

```bash
curl https://example.com
```

## Git

Basic commands:

```bash
git clone
git status
git add
git commit
git push
```
