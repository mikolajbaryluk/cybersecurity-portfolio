# HTTP Security Headers Checker

## Description

An educational project designed to learn about HTTP response headers related to web application security.

## Goal

The tool will check for selected security-related HTTP headers and display the results in a readable format.

## Skills Practiced

* HTTP
* Python
* HTTP requests and responses
* Security headers
* Basic automation
